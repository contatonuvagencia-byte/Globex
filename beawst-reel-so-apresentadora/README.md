# Reel "Só a apresentadora": Samanta Lopes

`out/reel-so-apresentadora.mp4` (1080×1920, 30fps, H.264 + AAC, 18s) e `out/capa-reel-so-apresentadora.png`.

Cenas: gancho (0–3s) · revelação (3–8s) · +25 anos / educadora / empreendedora (8–13s) · CTA com rosto, logo da feira e infos (13–18s).

Textos, cores, tempos e o recorte do rosto (`ASSETS.rosto`) ficam no `CONFIG` do topo de `video.html`. Renderizar: `node render.mjs`.
Sem `assets/trilha.mp3` é usada uma trilha provisória (`trilha.py`); com `assets/locucao.mp3` a trilha abaixa e as legendas aparecem.
