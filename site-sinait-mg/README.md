# Site SINAIT DS/MG

Site estático (HTML + CSS, sem dependências) recriado a partir do site Wix, na identidade visual do SINAIT DS/MG.

- `index.html`: início (hero, quem somos, notícias, convênios, petição, SINAIT nacional, filie-se, contato)
- `convenios.html`: os 6 convênios + Clube SINAIT
- `noticias.html`: as 12 notícias com busca
- `styles.css`: estilos; `img/`: imagens

Para editar textos, notícias ou convênios, altere `build.py` e rode `python3 build.py` (regenera as 3 páginas).
Para publicar, basta subir a pasta inteira em qualquer hospedagem estática (Netlify, Vercel, GitHub Pages, Hostinger etc.).
